# FPV Session Timer

Single-page session timer for FPV practice. Live at https://weefpv.github.io/session-timer/

## Controls

| Input | Before start | During warm-up | After warm-up |
|---|---|---|---|
| Space | Start with warm-up | (ignored) | +1 |
| Space ×2 | Start, skip warm-up | (ignored) | Undo last +1 |
| Space ×3 | | End | End |
| P | | Pause / resume | Pause / resume |

Settings (gear icon, top right) are saved per device.

Session descriptions are a snapshot of the ClickUp "01 Session menu" task, in the `SESSIONS` block in `index.html`.
